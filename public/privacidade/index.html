Privacidade

Para usar a agenda, você cria uma conta com e-mail e senha. Sua senha é protegida com hash Argon2id e nunca é armazenada em texto simples. Guardamos seu identificador de conta, e-mail, nome, telefone e os dados de seus agendamentos: serviço, profissional, horários, situação e observações.

Esses dados são usados para organizar os atendimentos e ficam disponíveis para você e para a administração autorizada da barbearia correspondente. Evite enviar informações sensíveis no campo de observações.

Os dados da agenda são armazenados no servidor. O aplicativo web mantém apenas recursos básicos para mostrar a tela de indisponibilidade sem internet; não guarda sua agenda em cache.

Para solicitar correção ou exclusão dos seus dados, fale com a barbearia pelo telefone (51) 99993-8323. Alguns registros podem precisar ser mantidos para obrigações aplicáveis.

Links para WhatsApp estão sujeitos à política desse serviço. Usamos um cookie de sessão para manter seu acesso, com duração máxima de 24 horas.
